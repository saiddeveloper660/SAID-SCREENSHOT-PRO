Step-by-Step: How to configure Google Drive OAuth (Bengali & English)

বাংলা নির্দেশিকা (Bangla):

  1. Google Cloud Console-এ যান (console.cloud.google.com) এবং একটি New Project তৈরি করুন।
  2. APIs & Services > Library-তে গিয়ে Google Drive API Enable করুন।
  3. OAuth consent screen-এ গিয়ে User Type: External নির্বাচন করুন এবং আপনার App Name (Said Screenshot Pro) ও Email দিন।
  4. Credentials > Create Credentials > OAuth client ID-তে ক্লিক করুন:
    • Application type: Chrome extension (অথবা Web application)
    • Item ID: Chrome extensions পেজে (chrome://extensions) আপনার Said Screenshot Pro-এর যে ID দেখাবে সেটি দিন।
  5. তৈরি হওয়া Client ID কপি করে উপরের ইনপুট বক্সে পেস্ট করে Save চাপুন!

English Instructions:

  1. Go to Google Cloud Console and enable the Google Drive API.
  2. Configure the OAuth consent screen with https://www.googleapis.com/auth/drive.file scope.
  3. Create an OAuth Client ID for Chrome App / Extension with your unpacked extension ID.
  4. Paste the Client ID into the box above and click Save.

Chrome Installation & Testing Guide

Complete beginner-friendly instructions to load and test Said Screenshot Pro.

Chrome-এ Extension ইনস্টল করার নিয়ম (Step-by-Step):

  1. Google Chrome ব্রাউজার ওপেন করুন।
  2. এড্রেস বারে টাইপ করুন: chrome://extensions এবং Enter চাপুন।
  3. উপরে ডান কোনায় থাকা Developer mode টগল সুইচটি ON করুন।
  4. উপরে বাম পাশে একটি নতুন বাটন দেখতে পাবেন: Load unpacked।
  5. Load unpacked বাটনে ক্লিক করে said-screenshot-pro ফোল্ডারটি সিলেক্ট করুন।
  6. সাথে সাথেই Said Screenshot Pro ব্রাউজারে ইনস্টল হয়ে যাবে!
  7. Chrome-এর উপরের ডান পাশে থাকা Puzzle আইকনে (Extensions) ক্লিক করে Said Screenshot Pro-এর পাশে থাকা Pin আইকনে ক্লিক করুন যাতে এটি সবসময় সামনে থাকে।
