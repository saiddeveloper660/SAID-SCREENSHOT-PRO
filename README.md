# Said Screenshot Pro (Google Chrome Extension)
**Capture Anything. Save Everything.**

A complete, production-grade Google Chrome Extension (Manifest V3) for visible viewport capture, drag-to-select area snips, automated scrolling full-page capture, custom scroll stitching, vector annotation editor, lossless PNG/JPG/WebP export, multi-page A4 PDF creation, and Google Drive cloud backup.

## 🚀 Chrome-এ ইনস্টল করার সহজ নিয়ম (Beginner Step-by-Step Guide)

1. **Google Chrome** ব্রাউজার ওপেন করুন।
2. এড্রেস বারে যান: `chrome://extensions` এবং **Enter** চাপুন।
3. ডান কোনার **Developer mode** সুইচটি **ON** করুন।
4. বাম পাশের **Load unpacked** বাটনে ক্লিক করুন।
5. আনজিপ করা `said-screenshot-pro` ফোল্ডারটি সিলেক্ট করুন।
6. Extensions আইকন (🧩) থেকে **Pin (📌)** করে সরাসরি ব্যবহার শুরু করুন!
